# Web Forms registration / feedback

## Create project
1. Visual Studio → Create a new project.
2. Choose **ASP.NET Web Application (.NET Framework)**.
3. Name it `WebFormsDemo`; select **Web Forms**.
4. Add the `.aspx` file and its `.aspx.cs` code-behind from this folder.
5. Ensure the `Inherits` namespace/class matches your project. If your project uses a different namespace, change it in both files.

`StudentRegistration.aspx` demonstrates Label, TextBox, RadioButton, DropDownList, CheckBox, Calendar and Button. Reuse the layout for employee registration by changing fields (employee ID, department, designation); use the same submit/output pattern.

For a Student Feedback Form, use TextBox for comments, RadioButtons for rating, CheckBoxes for aspects, a DropDownList for subject, and a Button that prints the values to a Label.
